### 📌 שלב 1 — התקנת Prometheus exporter במערכת

צור קובץ: `utils/metrics_exporter.py`

```python
from prometheus_client import Gauge, Counter, start_http_server

mode_gauge = Gauge("algogpt_mode", "Current system mode", ["mode"])
pnl_gauge = Gauge("algogpt_pnl", "Daily realized PNL")
open_positions = Gauge("algogpt_open_positions", "Active open trades")
failure_rate = Gauge("algogpt_failure_rate", "API failure %")
news_pause = Gauge("algogpt_news_pause", "News pause active (0/1)")
symbols_active = Gauge("algogpt_symbols_active", "Active scanning symbols count")

def start_metrics_server(port=9100):
    start_http_server(port)

def update_metrics(state):
    mode_gauge.labels(mode=state.mode).set(1)
    pnl_gauge.set(state.daily_pnl)
    open_positions.set(state.open_positions)
    failure_rate.set(state.api_fail_rate)
    news_pause.set(1 if state.news_pause else 0)
    symbols_active.set(len(state.symbols))
```

### ✅ תוצאה

Prometheus חושף נתונים → Grafana שואב → LIVE dashboard.

# ✅ חלק 2 — POST-TRADE AI EVALUATOR

### 📌 קובץ חדש: `utils/post_trade_ai.py`

```python
from openai import OpenAI
client = OpenAI()

def evaluate_trade(trade):
    prompt = f"""
    Evaluate this trade objectively:

    Symbol: {trade['symbol']}
    Result: {trade['pnl']}
    RR: {trade['rr']}
    Entry Type: {trade['setup']}
    Market: {trade['market']}
    SL Behavior: {trade['sl_behavior']}
    Exit Reason: {trade['exit_reason']}
    Duration: {trade['duration']} min

    Return JSON with:
    - score (0-10)
    - cause
    - fix
    - probability_improvement
    """

    resp = client.chat.completions.create(
        model="gpt-4.1",
        messages=[{"role": "user", "content": prompt}]
    )

    return resp.choices[0].message.content
```

# ✅ חלק 3 — AUTO-SCALING למולטיסמלים (אמיתי)

### 📌 קובץ: `utils/auto_scaler.py`

```python
class AutoScaler:
    def __init__(self):
        self.min_symbols = 5
        self.max_symbols = 40

    def compute(self, market):
        if market.volatility_high and market.trend_strong:
            return min(self.max_symbols, market.liquidity_score * 4)

        if market.choppy or market.news_risk:
            return self.min_symbols

        return int(self.min_symbols + (market.strength * 3))
```

### ✅ אינטגרציה ל-Auto-Executor

```python
from utils.auto_scaler import AutoScaler
```
