### ✅ **2) Workspace UI כמו Replit**

Implement:

* File tree browser
* Editor (Monaco Editor)
* Real-time save
* Terminal execution (isolated)
* Project switcher
* Status indicators (CPU/RAM/Errors)
* Hot-reload
* View logs live

Frontend must be React + Vite.

---

### ✅ **3) Backend יכולות**

Implement APIs:

```
GET  /files/tree
GET  /files/open?path=
POST /files/save
POST /exec/run
POST /project/switch
GET  /logs/live (WebSocket)
POST /health/self-heal
```

Rules:

* Sandboxed execution
* No system commands outside container
* Auto-restart on failure
* Logs persist

---

```
   project3/
```

Features:

* Create / Duplicate / Delete
* Switch with no restart
* Separate env per project
