# מה אתה מקבל עכשיו (Lite Mode, 4GB-Safe)

* **Benchmark חכם ללא עומס:** Freqtrade (לילי בלבד), Hummingbot (10 דק׳ כל שעה), Bitsgap בקריאה בלבד.
* **Analytics בענן (ללא זיכרון מקומי):** Grafana Cloud ל־Ops; Superset בענן/חלופה קלה ל־PnL (או דלג אם כבד).
* **שמירת משאבים:** PgBouncer (Pooling ל־Postgres), Resource Guards (CPU/RAM), Batch API (531→11 קריאות), WS Multiplex.
* **אבטחה מוקשחת:** Sandboxing להרצות benchmark (ללא רשת בזמן backtest), מפתחי Exchange **READ-ONLY** משותפים עם Rotation חודשי.
* **Data Science אמיתי:** נרמול מדדים (Sharpe/Win%/PF/DD), “Apples-to-Apples” (אותו טווח זמן), מבחנים סטטיסטיים בסיסיים.
* **Scorecard השוואתי:** טאב “Benchmarks” באתר – תקציר מנצח/מפסיד, Equity השוואתי, קישורים ללוחות המלאים.
* **תזמון חכם:** לעולם לא רצים שני כלים במקביל (00:00 Freqtrade, 02:00 HB 10min, 03:00 Bitsgap, 09:00/21:00 דוחות קיימים).
* **Guardrails 4GB:** CPU≤65%, RSS≤3.1GB (3.3→כיבוי bench קודם; 3.5→דילוג), p95<1.6s, SSE≥99%.
* **עלות שוטפת נמוכה:** ענן חינמי/זול, overhead זניח על השרת הראשי.

# הודעה אחת לסוכן Replit (להדבקה כמו שהיא)

**TASK NAME:** AlgoGPT — Benchmarks Lite (4GB-Safe) + Cloud Analytics + Guards

**מטרה:** לחבר Freqtrade/Hummingbot/Bitsgap ב־Lite Mode ללא עומס, לחבר Grafana Cloud (Ops) ו־Superset בענן (PnL) או לדלג על Superset אם כבד, ולהוסיף Guardrails/Pooling/Normalization + טאב “Benchmarks” באתר. לא נוגעים בביצוע טריידים מה־bench — קריאה בלבד.

**אל תשנה:** אבטחה/HMAC/Bearer/RBAC, Anti-Replay, Always-On/Blue-Green, Telegram (אישור בלבד), Cold-Wallet Pull-Only.

**בצע לפי הסדר:**

1. **Feature Flags + ENV (הפעל/כבה לפי צורך)**

   * `BENCH_FREQTRADE=on` · `BENCH_HBOT=on` · `BENCH_BITSGAP_RO=on`
   * `GRAFANA_CLOUD=on` · `SUPERSET_CLOUD=on|off`
   * `PGBouncer_ENABLE=on` · `RESOURCE_GUARDS=on` · `BATCH_API_ENABLE=on` · `WS_MULTIPLEX=on`

2. **PgBouncer (חובה, 4GB-safe)**

   * התקן והגדר Pool מקס׳ 20 חיבורים אפליקטיביים (session/transaction pooling).
   * ודא שכל ה־workers + אתר משתמשים ב־PgBouncer DSN.

3. **Scheduler (Lite Mode, בלי עומס)**

   * Freqtrade: ריצה לילית אחת (00:00), שמירת תוצאות ל־`/benchmarks/freqtrade/` ואז סגירה מלאה של התהליך.
   * Hummingbot: ריצה יבשה 10 דק׳ כל שעה (02:00־02:10 כברירת מחדל), שמירת סטטיסטיקות ל־`/benchmarks/hummingbot/`, סגירה מלאה.
   * Bitsgap: משיכת Snapshot יומי (03:00) ל־`/benchmarks/bitsgap/`.
   * לעולם לא להריץ שתי עבודות במקביל. הוסף backoff+jitter אם עומס.

4. **Security Sandboxing**

   * הרצות benchmark (FT/HB) ב־sandbox ללא רשת בזמן backtest/sim (או Docker/Firejail עם `--network=none`, `read_only`, `mem_limit`).
   * מפתחות בורסות **READ-ONLY** משותפים לשלושת הכלים, עם Rotation אוטומטי כל 30 יום.
   * Data masking בלוחות ענן (אין API keys בלוגים/יצוא).

5. **Shared Data Cache + Batch**

   * שכבת Cache משותפת (Redis) ל־OHLCV/Book כך שכלים לא יקראו מבורסה ישירות.
   * הפעל Batch לקיבוץ קריאות (531→≈11).
   * TTL שמרני (60–120s) ו־Cache stampede guard.

6. **Data Normalization + Scorecard**

   * תבנה pipeline שמאחד תוצאות ל־schema אחד (source, period, win%, PF, Sharpe, MaxDD, totalPnL, trades).
   * חישוב Composite Score (משקולות: Sharpe 25%, PF 20%, Win% 20%, −MaxDD 15%, PnL 10%, −AvgDur 10%).
   * מבחנים סטטיסטיים בסיסיים (t/MWU) ל־“האם AlgoGPT עדיף” על אותו חלון.

7. **Cloud Analytics (ללא זיכרון מקומי)**

   * Grafana Cloud: לוח Bench-Ops (CPU/RAM/p95/p99/SSE/429, סטטוס עבודות, דגלי degrade).
   * Superset בענן (או דלג אם כבד): לוח Bench-PnL (Equity/Win%/PF/Sharpe/DD, השוואות).
   * SSO/RBAC (Viewer לקריאה בלבד). אין Export ללא Admin.

8. **אתר — טאב “Benchmarks”**

   * תקציר חי: מי מוביל (Composite), Equity השוואתי, Win%/PF/Sharpe/MaxDD, #Trades.
   * חיבור SSE/Polling חכם (לא יותר מ־1×/10s).
   * קישורים ללוחות ענן (SSO).
   * מצב “Degrade” מוצג כשSkip בוצע עקב משאבים.

9. **Guardrails & SLOs**

   * עצור/דחה עבודת bench אם: `RSS>3.1GB` או `CPU>65%` או `429 burst`.
   * Kill מיד תהליכי bench אחרי סיום; אין שירותי bench רצים 24/7.
   * יעדים: SSE≥99%, p95<1.6s, p99<2.8s, אין חריגות חיבור DB (PgBouncer מחיל).

10. **Acceptance (להחזיר Owner Summary)**

* ריצת לילה אחת של Freqtrade עם קבצים תקינים + HB 10min + Bitsgap Snapshot.
* Grafana Cloud מציג Bench-Ops; טאב “Benchmarks” באתר פעיל עם נתונים חיים.
* מדידה: CPU/RSS במסגרת, לא יותר מתהליך bench אחד בכל רגע, אין 429 רציפים.
* דו״ח קצר (≤10 שורות): השוואה AlgoGPT מול FT/HB/BG + יוצאי דופן + הצעות Fine-Tune.

**מדיניות “לא חורגים מ־4GB”:**
אם יש קפיצה בזיכרון/CPU, תבצע **auto-degrade**: דחה Bench, שמור דגל Skip ודווח בטאב. אין פגיעה ב־AlgoGPT Core / ניהול טריידים חיים.

**אבטחה:** אין ביצוע הזמנות דרך Bench. הכול READ-ONLY, RBAC פעיל, Audit על כל ריצה (start/end/skip & reason).
