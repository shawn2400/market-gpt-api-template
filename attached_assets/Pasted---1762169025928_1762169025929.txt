## TASK NAME: AlgoGPT — Living Market Engine (Full Auto, Dynamic, 4GB/2CPU-Safe)

**מטרה:** להפוך את AlgoGPT למכונת החלטה וניהול חיה, דינמית ואוטומטית לחלוטין:
סורקת→מחליטה→מבצעת→מנהלת→לומדת→מתאימה את עצמה בזמן אמת לכל מצב שוק (חזק/חלש/צדדי/תנודתי), ב-Spot/Futures וריבוי בורסות ניתנות להוספה. כל טרייד—קטן או גדול—נכנס לניהול חי שממצה את הפוזיציה עד תום.

### Core Behaviors (חובה)

* **Live Regime Engine:** זיהוי Bull/Bear/Sideways/Volatile → התאמת פרמטרים (ATR-Trail N, TP Ladder 2–3 שלבים, Flip A+) דינמית.
* **Dynamic Entry Selector:** קונסנזוס 3 מוחות (GPT-5 / DeepSeek / AI-X) + News Impact Vector (impact, confidence) + ΔOI/Funding/Book.
* **Auto Execution Router:** Limit Post-Only, Fill-Prob Gate ≥0.62, No-Chase>0.3%, Idempotency מלא + Fallback venue.
* **Auto-Manage Always-ON:** SL→BE, ATR-Trail אדפטיבי, TP-Shift חכם, Partial exits, Flip A+ Guarded, Attach-Grid בתור נפרד.
* **Budget & Wallets Aware:** ניהול לפי יתרה חיה בארנק לכל בורסה; VaR-Live 0.8–1.2% לטרייד; Daily Loss Cap 2–3%; משיכת cold חד-כיוונית לפי כלל.
* **Learning Light-RL:** Bandit לפרמטרים (ATR-N/TP/Flip), Shadow vs Live, Curriculum על 50 תרחישי מפתח, Risk-Refit תקופתי.
* **Observer & Ops:** מבט-על חי, SSE batched, deep-links לאודיט, Ops Header עם KPIs; Toggle Telegram↔Web-Auto עם Cooldown 3s.

### Load & Safety (4GB/2CPU)

* Concurrency ליבה: **8**; ניהול פוזיציות במקביל: **עד 12**.
* Jobs כבדים (Backtest/Scenario/Correlation): **עד 2** בו-זמנית (Queue).
* SSE: batching **3–5s**, heartbeat 15s, עד 50 חיבורים (מעל זה → polling 5s).
* Memory guard: יעד RSS ≤ **3.2GB**; Auto-Degrade אם >3.4GB (כיבוי מדיה/אנימציות/וידאו).
* Top-K חם: **20** סמלים לניהול-על.

### Risk & Policy Guardrails (קשיח)

* **Exposure/Correlation guards**, Hedge חכם; Liquidation Sentinel (Reduce-Only אוטומטי).
* **Circuit Breakers per-Exchange** (Safe/Normal/Aggressive) עם מעבר אוטומטי ב-429/latency.
* **Freeze Lever:** הקפאת פתיחות חדשות כש-DD/VaR/CPU עוברים סף (ניהול קיימות ממשיך).
* **Secret Rotation 30d + Dual Keys**, Anti-Replay (±60s), HMAC+nonce+ts, RBAC Admin/Viewer.
* **n8n (5 Flows):** Incident Router, Approvals Fallback חתום, News Pre-Sanity קל, Macro De-Risk Scheduler, Webhook Gateway.

### Per-Exchange Visibility & Naming

* Tabs לפי VENUE (BINANCE_FUT / BYBIT_FUT / OKX_FUT / …), Snapshot חי של balances/positions/health.
* Policy שמות אחידה:

  * Trade: `TRD-{VENUE}-{SYMBOL}-{YYYYMMDD}-{SEQ}`
  * Grid:  `GRD-{VENUE}-{SYMBOL}-{YYYYMMDD}-{SEQ}`
  * Ticket: `TCK-{SOURCE}-{SYMBOL}-{TS}`

### Site & UX

* 8 Tabs + Observer&Ops + PWA; Command & Control (Execute, Close/Partial, Hedge, Flip A+, Grid Start/Stop, Kill-Switch/Economy-Mode).
* **Reports באתר בלבד** 09:00/21:00 + “Generate Now”; טלגרם רק Approve/Reject אם במצב Telegram.
* חיפוש/סינון <100ms (10k), Bundle ≤250KB gzip; תמונות/וידאו עם lazy+thumbnails/HLS.

### SLOs (מחייב)

* API p95 < **1.6s**, p99 < **2.8s**; SSE uptime ≥ **99%**.
* Entry→Auto-Manage hook start ≤ **200ms**; עדכוני ניהול ≤ **10s**.
* AI Cache-Hit ≥ **90%**; Budget Forecaster: התראה 80%, Auto-Pause 100%.
* אין כפילויות הזמנות בריטריי/פולבאק (Idempotency Audit ירוק).
* Reports נוצרים בזמן; Logs zstd + שמירה 90 יום; Audit hash-chain תקין.

### Acceptance (PASS)

1. כל טרייד (אישור/אוטומטי/ידני) נכנס אוטומטית ל-Auto-Manage ומדווח ב-SSE.
2. התאמות דינמיות של ATR-Trail/TP/Flip לפי Regime+Bandit נראות בדוחות.
3. מעבר אוטומטי ל-Safe באירועי עומס/429; חזרה ל-Normal מתועדת.
4. ניהול לפי ארנק חי לכל בורסה; משיכת cold חד-כיוונית פועלת לפי כלל; אין החזר אוטומטי מהקולד.
5. Shadow vs Live Report יומי מציג uplift; KPIs (Win-Rate/Profit-Factor/DD) משתפרים 14 יום רצוף תחת Guardrails.
6. RSS/p95 עומדים ב-SLO 72 שעות; Auto-Degrade פועל וחוזר.
7. Toggle Telegram↔Web-Auto עובד (Cooldown 3s, Double-Confirm), עם Audit+SSE.

### הנחיות לסוכן

* ליישם **מלא** (API+UI+Jobs+Observer+n8n), בדיקות, CI/CD, Release Notes.
* לא לשנות Auth/HMAC/Bearer/Anti-Replay — להשתמש בהם כמות שהם.
* כל רכיב חדש מאחורי **Feature Flag** + Kill-Switch; בלי Mesh/Kafka ב-4GB (Redis-Streams קל בלבד).
* להחזיר **Go-Live Package**: Observer Summary/Events, hash config-snapshot, Hardening Report (p95/p99, SSE uptime, AI cost/budget, cache-hit, CB/Sentinel actions, Shadow uplift).
