# ✅ חלק 1 — מודול ML-Prediction (5–15 דקות קדימה)

### 📌 קובץ: `utils/ml_predictor.py`

```python
# utils/ml_predictor.py

import numpy as np
from collections import deque

class MLPredictor:
    def __init__(self, window=50):
        self.window = window
        self.prices = deque(maxlen=window)

    def update(self, price):
        self.prices.append(price)

    def predict(self):
        if len(self.prices) < self.window:
            return None

        x = np.arange(len(self.prices))
        y = np.array(self.prices)

        coeff = np.polyfit(x, y, 1)
        slope = coeff[0]

        if slope > 0:
            return {"direction": "UP", "confidence": min(abs(slope) * 12, 1)}
        if slope < 0:
            return {"direction": "DOWN", "confidence": min(abs(slope) * 12, 1)}

        return {"direction": "FLAT", "confidence": 0.1}
```

```python
# utils/freeze_manager.py

import time
import redis

r = redis.Redis()

class FreezeManager:
    def freeze(self, symbol, minutes):
        r.setex(f"freeze:{symbol}", minutes * 60, 1)

    def is_frozen(self, symbol):
        return r.get(f"freeze:{symbol}") is not None
```

# ✅ חלק 3 — Heatmap ביצועים לכל מצב שוק

### 📌 קובץ: `utils/performance_heatmap.py`

```python
# utils/performance_heatmap.py

import numpy as np

class PerformanceHeatmap:
    def __init__(self):
        self.data = {}

    def update(self, mode, pnl):
        if mode not in self.data:
            self.data[mode] = []
        self.data[mode].append(pnl)

    def summary(self):
        return {
            mode: {
                "avg": round(np.mean(values), 3),
                "win_rate": round(sum(v > 0 for v in values) / len(values), 3),
                "trades": len(values)
            }
            for mode, values in self.data.items()
        }
```

# ✅ חלק 4 — שילוב הכל ב-Auto Executor

### 📌 בקובץ: `auto_executor.py`

```python
from utils.ml_predictor import MLPredictor
from utils.freeze_manager import FreezeManager
from utils.performance_heatmap import PerformanceHeatmap

ml = MLPredictor()
freeze = FreezeManager()
heat = PerformanceHeatmap()

def execute(symbol, price, mode, atr, pnl_last_trade):
    ml.update(price)

    if freeze.is_frozen(symbol):
        return None

    forecast = ml.predict()
    heat.update(mode, pnl_last_trade)

    if forecast and forecast["direction"] == "DOWN" and mode == "CHOPPY":
        return None

    return {"symbol": symbol, "size": atr * 12}
```
