מעולה — קיבלתי את הדוח. הנה “הודעה אחת להדבקה לסוכן” שמבצעת **את כל התיקונים הקריטיים** שעלו (ויותר): ולידציה סטטיסטית מלאה, הקשחת שערי החלטה (fail-closed), Monte-Carlo מבוסס נתונים אמיתיים, Dual-Confirmation כמותי+AI, ניטור חי וצ’קפוינטים (circuit breakers). הכל דינמי, פרודקשן, עם קבצים/Endpoints/DB/ENV/בדיקות קבלה.

**TASK NAME:** AlgoGPT — Validation & Hardening v1 (Backtest+Dual Gates+Data-Driven SL/TP+Live Monitors)

**GOAL:**

1. לאשר פרודקשן **רק** אחרי הוכחת edge סטטיסטית (Backtest/WFT).
2. להקשיח החלטות: **fail-closed** (בלי fallback-to-defaults), **Dual-Confirmation** (כמותי ∧ AI), ומסגרות RR/SL/TP אמפיריות.
3. ניטור חי + Circuit Breakers (עצירה אוטומטית בשבירה), דוחות/מדדים/טלגרם.
4. לשמר את ה־SOP והאבטחה (Bearer/HMAC), בלי עומסים, עם Cache וריסון קריאות.

## 3) שינוי קריטי בלוגיקת החלטה (Fail-Closed + Dual)

**החלף** ב־`utils/decision_engine.py`:

```python
# ❌ קודם (פרמיסיבי)
# approved = (approved_prob or legacy_ok) and (veto is None)

# ✅ עכשיו (מחמיר + תיעוד חסימה)
approved, block_reason = dual_gate_decision(
    quant_score=signal.quant_score,
    ai_score=signal.ai_score,
    rr=signal.expected_rr,
    risk_ok=risk_flags.all_passed,
    cfg=cfg
)
if not approved:
    return Reject(reason=block_reason, trace=trace_id)
```

והסר כל fallback מסוכן:

```python
# ❌ אל תעשה:
x = feed or 0.0

# ✅ כן:
if feed is None:
    raise CriticalDataMissing("feed missing: can't proceed")
```

## 7) בדיקות קבלה (חובה)

* [ ] `run_backtest` על 180–240 ימים, 6 folds → Winrate≥MIN_WINRATE_PCT, RR≥MIN_EXPECTED_RR; אחרת **לא** לשחרר ל-LIVE.
* [ ] MC-SL/TP נותן מולטי־פליירים שונים לפי Regime/ATR/ADX, ומקטין Stopouts ביחס לגרסה הישנה.
* [ ] Dual-Gate חוסם טרייד כש־(quant<min ∨ ai<min ∨ rr<min ∨ risk_fail) ומחזיר סיבת חסימה בשקיפות.
* [ ] Breaker פועל כש־win% 30d < 40% או 7d-DD > 8% או consec SL ≥ 4 → מבצע `PAUSE_AND_ALERT`.
* [ ] אין אף שימוש ב־fallbacks רכים בקלטים קריטיים (בדיקת grep).
* [ ] דוחות PDF/CSV נוצרים ונשלחים לטלגרם + זמינים ב־Dashboard “Finance & Reports”.

## 8) Rollout (בטוח)

1. להריץ `/validate/run` על Universe הסמלים המרכזי.
2. אם **Pass** → להפעיל `DUAL_CONFIRM_ENABLE=1` ו־`VALIDATION_REQUIRED=1`.
3. 48 שעות Canary עם Breakers “ON”, ואז Rollout מלא.
