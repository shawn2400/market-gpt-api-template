## **TASK NAME:** AlgoGPT — GitHub Full Features & Indicators Ingest (Server+Rider, 4GB-safe)

**מטרה:**
למשוך באופן מאובטח את *כל* האינדיקטורים, הסורקים, והפיצ’רים מריפו(ים) ב-GitHub, למפות אותם למודולים מוכרים במערכת, לאפשר הפעלה/כיבוי דרך **Feature Flags**, להריץ בדיקות+בניית דוקומנטציה אוטומטית, ולחבר הכל ל־**Observer / Website / Auto-Manage** — בלי לשבור תאימות, ובלי לעבור את מגבלות 4GB/2CPU.

---

### Deliverables (חובה)

1. **GitHub Sync (מאובטח, Read-Only + PR Flow)**

* קונפיג: `GIT_REMOTE_URL` + branch ברירת מחדל `main` (או `prod` אם קיים).
* Clone/update לצל של הריפו/ים ב־`/opt/algogpt/external/` (ללא סודות; מחיקה אוטומטית של קבצי מפתח).
* ניטור שינויי קבצים רק תחת נתיבים מותרים:

  * `indicators/**`, `scanners/**`, `strategies/**`, `risk/**`, `utils/**`, `routes/**`, `config/**`.
* כל שינוי → **PR אוטומטי** ל־repo הראשי של AlgoGPT עם Diff מפורט (מה נוסף/שונה/נמחק), CI ירוק חובה.

2. **Indicator & Feature Registry**

* בניית רישום מרכזי:

  ```
  registry/
    indicators.json   # שם, גרסה, קלט/פלט, תלויות
    scanners.json
    strategies.json
    risk_rules.json
    features.json     # מיפוי -> FEATURE_FLAGS
  ```
* סטנדרט I/O לכל אינדיקטור: dataframe in → dict metrics out (עם שמות שדות אחידים: rsi, macd, ema21/50, atr, adx, bbands, obv, vol_spike, וכו’).
* וולידציה עם **zod/pydantic**; אי התאמה → סימון “quarantined” (לא נטען לפרוד).

3. **Feature Flags (מרוכז)**

* `FEATURE_INDICATORS_*`, `FEATURE_SCANNERS_*`, `FEATURE_STRATEGY_*`, `FEATURE_RISK_*`.
* Toggle דרך Settings באתר + API חתום (`/ops/feature-flags`), עם Audit + SSE event.
* פרופילים: `SAFE` (מינימליסטי), `NORMAL` (דיפולט), `AGGRESSIVE` (סט בלבד, מאחורי דגל).

4. **Auto-Manage Integration (Plug-in)**

* כל אינדיקטור/סורק שנכנס → מתחייב ל־contract:

  * זמני ריצה: ≤ 80ms ל־symbol (p95) על טווח Klines מוגדר.
  * גודל זיכרון: ≤ 32MB זמני לאלגוריתם.
* אם חורג: **Throttle/Skip** אוטומטי + flag `degraded`.
* Position-AI קורא *רק* מה־registry המאושר.

5. **Observer & Website**

* לשונית **Observer & Ops**:

  * “External Packs” card: כמה אינדיקטורים/פיצ’רים נטענו, גרסאות, זמן טעינה, חריגות.
  * Deep-link ל־Audit של כל Pack/Commit.
* **Markets/Trades/Positions** מציגים שדות מדדים חדשים כאשר flags פעילים (tooltips + מקור).

6. **Rider Integration**

* Rider חובר לריפו(ים) עם הרשאות **קריאה+PR בלבד** (ללא push ישיר ל-prod).
* פקודות זמינות: `validate-packs`, `run-unit-tests`, `bench-indicators`, `open-pr`, `deploy-staging`.
* כל פקודה תחת **rate-limit** (Queue), תיעוד ל־Audit.

7. **CI/CD + Quality Gates**

* בדיקות יחידה לאינדיקטורים (I/O contracts), בדיקות ביצועים (micro-bench), בדיקות אינטגרציה בסיסיות (scan+route+manage).
* Gate: זמן ריצה כולל ≤ 3 דקות, RSS ≤ 3.2GB, p95 API < 1.6s.
* כשל ב-Gate → **אין פריסה**, PR נשאר “red”.

8. **Docs & Examples (אוטומטי)**

* יצירת **Markdown** לכל אינדיקטור/סורק/פיצ’ר: שם, פרמטרים, דוגמה, גבולות; שמירה ב־`/docs/packs/` והצגה ב־Settings → “Catalog”.
* דף “How to contribute indicators” (תבנית+בדיקות).

9. **Security & Audit**

* כל commit מ-GitHub → hash + חתימה ב-Audit chain.
* סודות מושחרים `****last4`, אין קריאה ל־`.env` חיצוני.
* **Anti-Replay (±60s)**, HMAC+nonce+ts בכל webhook מ-GitHub Actions/Rider.

10. **Load & Memory Guards (4GB-safe)**

* Top-K symbols חמים = 20 לניהול-על; הרחבה ידנית בלבד.
* SSE backpressure פעיל; מעל 50 חיבורים → Polling 5s.
* Auto-Degrade למדיה/גרפים אם RSS > 3.4GB; חזרה אוטומטית כשיורד.

---

### SLOs (מחייב)

* Pack ingest (clone+validate+register): **≤ 90s** לפריסה.
* אינדיקטור בודד: **≤ 80ms** (p95) ו־RSS אלגוריתם **≤ 32MB** זמני.
* API p95 **< 1.6s**, p99 **< 2.8s**.
* CI pack-suite **≤ 3m**; Cache-hit ≥ **90%** לשאילתות חוזרות.

---

### Acceptance (PASS)

1. **registry/** נוצר ומציג X אינדיקטורים, Y סורקים, Z פיצ’רים, עם גרסאות ו-hash.
2. Feature Flags פועלים מהאתר+API, עם Audit + SSE event.
3. דוחות “External Packs” ב-Observer; Deep-links ל-PR/Commit/Bench.
4. כל אינדיקטור עומד ב-contract (זמן/זיכרון); חורגים מסומנים quarantined.
5. רכיב Auto-Manage קורא רק מאושרים; עומד ב־SLO.
6. Rider מפעיל validate/bench/open-PR/deploy-staging בהצלחה; PR ירוק בלבד מגיע ל-prod.
7. CI/CD Gate חוסם פריסות חמות כש-SLO נשבר; Auto-rollback ל-N-1.
8. אין הדלפת סודות; כל webhook חתום; Anti-Replay פעיל.

---

### מגבלות והנחיות

* **לא לשנות** מנגנוני Auth/HMAC/Bearer/Anti-Replay הקיימים — רק להשתמש.
* בלי Mesh/Kafka ב־4GB; Redis-Streams *רק אם* חייבים Queue-ID, עם TTL קצר.
* כל פיצ’ר חדש מאחורי **Feature Flag** + Kill-Switch.
* Polling ≥ 60s עם backoff+jitter; אין לולאות חמות.
* שמירה על Naming Policy בכל מקום.
