## Deliverables

### A) Observer Aggregator (שירות לייט, חתום)

* Endpoints (Read-only, HMAC + nonce + ts):

  * `GET /observer/summary` → מצב מערכת מאוחד (p95/p99, CPU/MEM, queues, ratelimits, SSE uptime, AI cost/budget, cache-hit, wallets runway).
  * `GET /observer/events?limit=100` → 100 אירועים אחרונים מכל הרכיבים (Core/Site/AI/n8n/GitHub/Render/Exchanges).
  * `GET /observer/config-snapshot` → קונפיג מרוכז **מושחר** (****last4, בלי סודות), עם hash+timestamp.
  * `GET /observer/health` → בכל רכיב: OK/WARN/FAIL עם סיבה.
  * `GET /observer/topology` → דיאגרמת תלותים (JSON) של כל השירותים והחיבורים.

* SSE:

  * `GET /observer/sse` → batching כל 3–5s; heartbeat כל 15s; עד 50 חיבורים (מעבר → polling 5s).

* איסוף:

  * Core/Site: מדדים דרך endpoints קיימים.
  * AI Providers (GPT-5/DeepSeek/AI-X): ping זול + רישום עלות/latency/שגיאות.
  * n8n: executions/status דרך webhook חתום.
  * GitHub: latest commit/PR statuses (read-only).
  * Render: deploy status/health.
  * Rider: task logs (read-only).
  * Exchanges: rate-limit/nonce-drift/ping.

> 4GB-safe: אין פולינג חם; כל polling ≥ 60s, backoff+jitter, Top-K בלבד.

### B) Website — לשונית “Observer & Ops”

* **Panels**: Summary, Events Live, Health Map, AI Cost/Budget, FinOps, Queues, Wallets (runway/redacted), Topology.

* **Controls (Admin בלבד, חתום)**:

  * `/control/execution-mode` (TELEGRAM↔WEB_AUTO) — כפי שהוגדר.
  * `/emergency/kill-switch`, `/economy-mode`, `/freeze-noncritical`.
  * `/ops/restart/{service}` (Core/Site/Worker יחיד) — ריסטרט ממוקד בלבד.
  * `/ops/rollback/site?to=N-1` / `/ops/rollback/core?to=N-1`.
  * `/ops/feature-flags` — הדלקה/כיבוי פיצ’רים כבדים (גרפים/וידאו/אנימציות/Backtests).

* **RBAC & אבטחה**: Replit Auth (Admin/Viewer), HMAC+nonce+ts, CSRF+SameSite=Strict, CSP/HSTS, WebAuthn אופציונלי לפקודות מסוכנות.

### C) Persistence & Backups

* **GitOps**: כל שינוי קונפיג/דגל/מדיניות → Commit חתום + CHANGELOG.
* **Artifacts**: דוחות יומיים (Core Guardian, Site Guardian) ב־`/reports` + העלאה ל-GitHub.
* **Backups**: snapshot יומי (DB/redis-meta) + אחסון S3-compatible (או Replit persistence) 7–14 ימים.
* **Rollback**: build N-1 (Site) / release N-1 (Core) בלחיצה אחת.

### D) n8n Bridge (אופציונלי אך מומלץ)

* Incident Router → קורא `/economy-mode`/`/freeze-noncritical` בעת עומס.
* Approvals Fallback (אם TELEGRAM down) → form חתום לליבה.
* News Pre-Sanity קל (allowlist+dedup) אם ingest עמוס.

### E) Rider + GitHub + Render

* Rider מחובר לריפו → יכול להריץ refactor/tests/deploy מאושרים (Admin בלבד).
* GitHub Actions: CI ירוק חובה; Deploy ל-Render (staging→prod, gate).
* Render hooks: בריאות, auto-rollback אם LCP/CLS/bundle/SSE לא עומדים ב-SLO.
