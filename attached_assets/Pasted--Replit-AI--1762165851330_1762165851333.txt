## 📩 TASK NAME: AlgoGPT — Unified Guardian (System + Site, Self-Heal, 4GB-safe)

**מטרה:** סוכן תחזוקה אחד שמנטר ומתקן **את כל המערכת והאתר** באופן אוטומטי: זיהוי תקלות, הפעלה/כיבוי פיצ’רים, רולבאק לגירסה יציבה, ותיעוד. לשמור על יעדי ביצועים (SLO) בלי להעמיס על 4GB/2CPU.

### 📡 Monitors (כל 60–180 שנ׳, קל משקל)

**Site**

* `/readyz` 200 + latency p50/p95
* `/sse/health` — heartbeat ≥1 בתוך 20s
* Assets: `index.html`/bundle/CSS — 200/304 + SRI match
* Markets smoke: DOM-marker נטען
* Lighthouse-Lite יומי: LCP/CLS + bundle size

**Core**

* `/metrics` מדדים עיקריים (p95 API, queue depth)
* Binance+Exchanges: ping/ratelimit/nonce-drift
* Redis/DB: ping + latency
* AI Providers: ping זול (GPT-5/DeepSeek/Grok) + route sanity
* FinOps: token burn/day + budget %
* Jobs: backtests/correlations/ingest queue age

### 🛠️ Auto-Remediation (סדר פעולות מחייב)

1. **SSE Watchdog (Site):** אין heartbeat→ reset קל; כשל כפול→ fallback Polling 3s ל-10 דק׳.
2. **Feature Flags (Site):** אם LCP>2s או bundle>250KB→ כבה חדשות-מדיה כבדה/אנימציות/חישובי-קליינט, העבר ל-text-first.
3. **Economy Mode (Core):** אם p95 API>1.6s או token-burn↑→ נתק מודולי אנליטיקה/Backtests, השאר Execution/Positions/Health בלבד.
4. **Rate-Limit Guard (Exchanges):** 429/5xx→ backoff+jitter, הורד פרופיל (Aggressive→Normal→Safe), הפעל circuit-breaker ל-venue ו-fallback ל-אחר.
5. **AI Router Safe:** ספק נופל→ route למחליף; אם budget≥80%→ auto-pause לשאילתות יקרות, Cache-Only לשאלות חוזרות.
6. **Cache Repair:** Redis miss-storm→ warm-up סלקטיבי (Top-K), purge למפתחות פגומים.
7. **CDN/Assets Repair (Site):** SRI mismatch→ purge `/assets/*` + refresh manifest.
8. **Service Restart (ממוקד):** ריסטארט worker/route ספציפי (לא כל השרת).
9. **Rollback יציב:** שני מחזורי תיקון ללא שיפור→ החזר ל-Build N-1 (Site) / Release N-1 (Core), שמירת diff.
10. **Escalate:** אחרי רולבאק כושל→ השבת פיצ’רים לא-קריטיים, דו״ח חריג.

### 🔒 Safety Rails (לא לשבור)

* אין שינוי auth/חתימות/HMAC/Bearer
* אין הפעלת ארביטראז’/Kafka/Service-Mesh
* אין שליחת דוחות לטלגרם (Approve/Reject בלבד)
* רוטציית סודות: גרסה חדשה פעילה במקביל ל-ישנה X דקות → מחיקה בטוחה

### 🎯 SLO Targets

* **Site:** LCP < 2.0s, TTI < 3.0s, bundle ≤ 250KB, SSE uptime ≥ 99%, p95 < 1.6s
* **Core:** p95 API < 1.6s (p99 < 2.8s), queue wait < 5s, error-rate < 1%
* **AI/FinOps:** chat < 2s, cache-hit ≥ 90% לשאלות חוזרות, budget alerts @80%
* **Exchanges:** no rate-limit breaches; route+place internal ≤ 150ms

### ✅ Acceptance (PASS Criteria)

* הסוכן מזהה ופותח **Economy Mode** בזמן עומס ומחזיר **Normal** כשנרגע
* ניתוק SSE יזום→ fallback Polling ואז חזרה ל-SSE
* 429 בבינאנס→ circuit-break ל-Binance + ביצוע ב-Bybit/OKX עם idempotency
* Cache-hit לשאלה חוזרת ≥ 90%
* רולבאק N-1 עובר ומתקן LCP/שבירת UI
* דו״ח Remediation מסכם: מזהה→צעדים→תוצאה (OK/ROLLED BACK)

### 🧾 Outputs (דוחות/לוגים)

* **Site Guardian Report** (יומי ו-on-incident): KPIs (LCP/CLS/bundle/SSE uptime), אירועים, פעולות, before/after
* **Core Guardian Report:** p95/p99, queue depth, ratelimits, AI routing, budget, rollbacks
* **Change Log:** כל Flag/Restart/Rollback עם timestamp ו-diff קצר

### 🧪 10-Minute Smoke (להוכחת חיים)

1. נתק רשת 30ש׳ → SSE fallback וחזרה אוטומטית
2. הדלק בכוונה וידאו/תמונות כבדים → הסוכן מכבה ומחזיר ל-text-first
3. דמה 429 ב-Binance → route ל-Bybit, אין הזמנה כפולה
4. העלה bundle דמו ל-260KB → הסוכן מכבה ווידג’טים עד חזרה ל-≤250KB
5. השאל אותה שאלה ×5 → cache-hit ≥90%
6. הורד זמנית DeepSeek → ניתוב GPT-5/Verify תקין
7. גרום לכשל Build אתר → Rollback ל-N-1 וה-LCP יורד ל-<2s
