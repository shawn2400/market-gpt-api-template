# ✅ **פקודה אחת לסוכן — התקנה מלאה במכה**

```
Task: Deploy FULL core-control-server system in one shot.

============================================================
1) CREATE PROJECT STRUCTURE
============================================================

Create folder:
core-control-server/

Inside create files exactly:

core-control-server/
 ├─ app/
 │   ├─ main.py
 │   ├─ auth.py
 │   ├─ file_manager.py
 │   ├─ exec_manager.py
 │   ├─ websocket_manager.py
 │   ├─ audit.py
 │   └─ settings.py
 ├─ requirements.txt
 ├─ Dockerfile
 ├─ docker-compose.yml
 ├─ run.sh
 ├─ .env.example
 └─ render.yaml

============================================================
2) ADD FULL Dockerfile
============================================================

FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000

CMD ["bash", "run.sh"]

============================================================
3) ADD docker-compose.yml
============================================================

version: "3.9"

services:
  core-control:
    build: .
    container_name: core-control
    restart: unless-stopped
    env_file: .env
    volumes:
      - ./workspace:/workspaces
    ports:
      - "8000:8000"

============================================================
4) ADD run.sh
============================================================

#!/bin/bash
uvicorn app.main:app --host 0.0.0.0 --port 8000

chmod +x run.sh

============================================================
5) ADD .env.example
============================================================

ADMIN_TOKEN=CHANGE_ME_BEFORE_RUN

============================================================
6) INSTALL SCRIPT (ONE CLICK)
============================================================

Create install.sh:

#!/bin/bash
set -e

echo "✅ Creating workspace..."
mkdir -p workspace

echo "✅ Copying .env..."
cp .env.example .env

echo "✅ Starting containers..."
docker compose up -d --build

echo "✅ System ready!"
echo "➡ Open: http://localhost:8000"
echo "➡ Use header: Authorization: Bearer <ADMIN_TOKEN>"

chmod +x install.sh

============================================================
7) RENDER DEPLOY SUPPORT
============================================================

Add render.yaml:

services:
  - type: web
    name: core-control-server
    env: docker
    plan: starter
    region: frankfurt
    dockerfilePath: ./Dockerfile
    envVars:
      - key: ADMIN_TOKEN
        sync: false

============================================================
8) COMPLETION CONDITIONS
============================================================

✔ Single-user system only  
✔ No trading features  
✔ Full terminal over WebSocket  
✔ File editor + run commands  
✔ Audit log enabled  
✔ Auto-start on reboot  
✔ Ready for expansion (AI, dashboard, agents)  
✔ No missing components  
✔ Zero manual config after install

============================================================
9) EXECUTION
============================================================

After deploy:

1) run:
   ./install.sh

2) open browser:
   http://localhost:8000

3) authenticate with:
   Authorization: Bearer ADMIN_TOKEN

============================================================
END OF TASK
============================================================
```
