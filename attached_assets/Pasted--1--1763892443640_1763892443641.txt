## 🔥 **פקודה לסוכן — ENABLE FULL AUTO-SCALING & AUTO-UPGRADE**

**Task:** להפוך את כל המערכת לאוטונומית לחלוטין — מתרחבת, משדרגת ומתאימה משאבים לבד, ללא אישור ידני.

### ✅ **1) AUTO-SCALING משאבים (CPU / RAM / Workers)**

להוסיף שירות חדש:

`/usr/local/bin/algogpt-autoscale.sh`

```bash
#!/usr/bin/env bash

CPU_LOAD=$(uptime | awk '{print $(NF-2)}' | sed 's/,//')
RAM_FREE=$(free -m | awk '/Mem/ {print $7}')

# Scale up
if (( $(echo "$CPU_LOAD > 0.75" | bc -l) )) || [ $RAM_FREE -lt 800 ]; then
  docker compose -f /opt/algogpt-agent/app/docker-compose.yml up -d --scale worker=3
  echo "✅ Auto-scale UP triggered"
  exit 0
fi

# Scale down
if (( $(echo "$CPU_LOAD < 0.40" | bc -l) )) && [ $RAM_FREE -gt 2000 ]; then
  docker compose -f /opt/algogpt-agent/app/docker-compose.yml up -d --scale worker=1
  echo "✅ Auto-scale DOWN triggered"
  exit 0
fi
```

להפעיל:

```bash
chmod +x /usr/local/bin/algogpt-autoscale.sh
(crontab -l 2>/dev/null; echo "*/10 * * * * /usr/local/bin/algogpt-autoscale.sh") | crontab -
```

✔ המערכת מתאימה את עצמה לבד
✔ לא צריך ריסטארט
✔ אפס התעסקות ידנית

### ✅ **2) AUTO-UPGRADE ללא אישור**

להוסיף:

`/usr/local/bin/algogpt-autoupdate.sh`

```bash
#!/usr/bin/env bash
cd /opt/algogpt-agent/app

git fetch --all
LOCAL=$(git rev-parse HEAD)
REMOTE=$(git rev-parse origin/main)

if [ "$LOCAL" != "$REMOTE" ]; then
  echo "⚡ Auto-upgrade triggered"
  git reset --hard origin/main
  docker compose down
  docker compose up -d --build
fi
```

להפעיל:

```bash
chmod +x /usr/local/bin/algogpt-autoupdate.sh
(crontab -l 2>/dev/null; echo "0 */4 * * * /usr/local/bin/algogpt-autoupdate.sh") | crontab -
```

✔ מתעדכן לבד
✔ נבנה מחדש אוטומטית
✔ תמיד רץ על הגרסה האחרונה
