# ✅ **A) עדכון install.sh — עם Auto-Backup + Self-Healing + Watchdog**

החלף את החלק התחתון ב־install.sh אחרי שלב 6:

```bash
### ===== 7) ENABLE AUTO-BACKUP =====
mkdir -p /opt/algogpt-backups

cat > /usr/local/bin/algogpt-backup.sh <<'EOF'
#!/usr/bin/env bash
set -e

TS=$(date +"%Y-%m-%d_%H-%M-%S")
BACKUP_FILE="/opt/algogpt-backups/backup_$TS.tar.gz"

tar -czf "$BACKUP_FILE" /opt/algogpt-agent/app/data || exit 1
echo "✅ Backup created: $BACKUP_FILE"
EOF

chmod +x /usr/local/bin/algogpt-backup.sh

# run every 6 hours
(crontab -l 2>/dev/null; echo "0 */6 * * * /usr/local/bin/algogpt-backup.sh") | crontab -


### ===== 8) ADD 1-CLICK RESTORE =====
cat > /usr/local/bin/algogpt-restore.sh <<'EOF'
#!/usr/bin/env bash
set -e

LATEST=$(ls -t /opt/algogpt-backups | head -1)

if [ -z "$LATEST" ]; then
  echo "❌ No backups found"
  exit 1
fi

tar -xzf "/opt/algogpt-backups/$LATEST" -C /
docker-compose -f /opt/algogpt-agent/app/docker-compose.yml restart
echo "✅ Restore completed from $LATEST"
EOF

chmod +x /usr/local/bin/algogpt-restore.sh


### ===== 9) SELF-HEALING WATCHDOG =====
cat > /usr/local/bin/algogpt-watchdog.sh <<'EOF'
#!/usr/bin/env bash

CONTAINER="algogpt-control-agent"

if ! docker ps | grep -q "$CONTAINER"; then
  echo "⚠️ Watchdog: restarting..."
  docker-compose -f /opt/algogpt-agent/app/docker-compose.yml up -d
fi
EOF

chmod +x /usr/local/bin/algogpt-watchdog.sh

# check every 5 minutes
(crontab -l 2>/dev/null; echo "*/5 * * * * /usr/local/bin/algogpt-watchdog.sh") | crontab -


### ===== 10) ENABLE AUTO-RECOVERY =====
echo "✅ Self-healing + auto-backup enabled"
```

✅ עכשיו יש לך:
✔ גיבוי אוטומטי כל 6 שעות
✔ שחזור בלחיצה אחת
✔ watchdog שמעלה את המערכת לבד
✔ אפס התעסקות ידנית

# ✅ **C) הוסף Audit Log בלתי-מחיקה**

בקובץ `main.py`:

```python
from utils.audit import audit_log

@app.middleware("http")
async def audit_middleware(request, call_next):
    response = await call_next(request)
    audit_log(request, response)
    return response
```

`utils/audit.py`:

```python
import json, time, os

LOG_FILE = "/opt/algogpt-agent/audit.log"

def audit_log(request, response):
    entry = {
        "ts": time.time(),
        "path": request.url.path,
        "method": request.method,
        "status": response.status_code
    }
    with open(LOG_FILE, "a") as f:
        f.write(json.dumps(entry) + "\n")
    os.chmod(LOG_FILE, 0o444)  # read-only
```

✅ תוצאה:
✔ אי-אפשר למחוק לוגים
✔ כל פעולה מתועדת
✔ עמיד בפני פריצה
