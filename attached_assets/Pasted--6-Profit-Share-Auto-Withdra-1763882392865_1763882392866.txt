# 🔥 שלב 6 — מערכת Billing + Safety אוטומטית

## ✅ 1) Profit-Share אוטומטי (18%)

### קובץ חדש: `utils/profit_share.py`

```python
import time
from utils.pnl_tracker import get_weekly_pnl
from utils.telegram_notifier import send_user, send_admin

PROFIT_RATE = 0.18

async def weekly_billing(user):
    pnl = get_weekly_pnl(user)
    if pnl <= 0:
        return

    amount = round(pnl * PROFIT_RATE, 2)

    await send_user(user, f"""
💰 Weekly Profit Share Summary

Total Weekly PNL: ${pnl}
Your Fee (18%): ${amount}

Please send USDT within 24h.
Failure = auto-suspension.
""")

    await send_admin(f"Billing issued for {user} → ${amount}")
```

### Scheduler ב־`main.py`

```python
schedule.every().sunday.at("23:00").do(run_weekly_billing)
```

## ✅ 3) Auto-Withdraw Profit Buffer

### קובץ: `utils/auto_withdraw.py`

```python
import binance_client as binance

THRESHOLD = 500  # USD
TARGET_BUFFER = 300

def auto_withdraw():
    balance = binance.get_balance("USDT")

    if balance > THRESHOLD:
        amount = balance - TARGET_BUFFER
        binance.withdraw("USDT", amount, COLD_WALLET_ADDRESS)

        return {
            "withdrawn": amount,
            "remaining": TARGET_BUFFER
        }
```

Scheduler:

```python
schedule.every().day.at("03:00").do(auto_withdraw)
```

## ✅ 4) Insurance-Mode (Hedge + Reduce)

קובץ: `utils/insurance_mode.py`

```python
def insurance_check(position, funding_rate, volatility):
    if funding_rate > 0.05 or volatility > 4.0:
        return {"hedge": True, "reduce": 0.3}

    if position.unrealized_pnl < -0.03:
        return {"hedge": True, "reduce": 0.5}

    return {"hedge": False}
```

ב־trade_manager:

```python
ins = insurance_check(pos, funding, vol)

if ins["hedge"]:
    open_hedge(symbol, size=ins.get("reduce", 0.3))
```

## ✅ 5) Fraud / Anomaly Detector

קובץ: `utils/anomaly_detector.py`

```python
def detect_anomaly(trades):
    if len(trades) < 5:
        return False

    losses = [t for t in trades[-5:] if t.pnl < 0]

    if len(losses) == 5:
        return "FULL_RED"

    if sum(abs(t.pnl) for t in losses) > 0.12:
        return "SEVERE"

    return False
```

ב־auto_executor:

```python
flag = detect_anomaly(recent_trades)

if flag == "FULL_RED":
    pause_system("AUTO")
```
