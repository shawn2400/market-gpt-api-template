TASK NAME: AlgoGPT — External AI Reviewers (Cohere + Mistral + Perplexity + OpenRouter), Lite & Secure

GOALS:
1) Service חדש: utils/external_review.py
   - פונקציה review_snapshot() שמייצאת Summary סטרוקטורלי (ללא סודות!):
     • Infra & SLO (CPU/RSS/429/SSE)
     • Risk rules (VaR, D.Loss Cap, ATR/ADX/BE/Trail)
     • Execution (Batch, WS-Mux, Fill-Prob, Slippage caps)
     • Strategy set (Futures/Grid/Spot, 7 strategies, Regime gates)
     • Security (HMAC/Anti-Replay/MFA/Rotation)
     • Costs (AI, infra), Bench (Freqtrade/Hbot/Lean/TV)
   - Scrubber: מסיר מפתחות/סודות/כתובות פנימיות; אנונימיזציה לסימבולים (BTC→SYM_001).
   - Envelope אחיד לשאלה: “Audit+” עם צ’קליסט ניקוד (0–10) לכל סעיף + המלצות “High/Medium/Low”.

2) Providers (כפופים ל־ENV flags):
   - Cohere Command-R+  (ENV: COHERE_API_KEY, EXTREV_COHERE=on)
   - Mistral Large      (ENV: MISTRAL_API_KEY, EXTREV_MISTRAL=on)
   - Perplexity Sonar   (ENV: PPLX_API_KEY,   EXTREV_PPLX=on)
   - OpenRouter Gateway (ENV: OPENROUTER_KEY, EXTREV_OPENROUTER=off by default)
   • כל קריאה עם hard cap: max_tokens, timeout=25s, retries=0, ורכיב cache.

3) Storage & Scoring:
   - טבלת DB: external_reviews(id, provider, started_at, finished_at, tokens, cost_usd, raw_json, 
     category_scores JSONB, overall_score FLOAT, top_risks TEXT[], top_actions TEXT[])
   - Normalizer: מאחד פורמטים -> category_scores: {infra, security, risk, execution, analytics, costs, governance}
   - Aggregator: “Consensus Score” (משוקלל) + “Disagreements” (סטיית תקן בין מודלים).

4) API & UI:
   - POST /external-review/run   (Admin, Bearer+HMAC)  ⇒ Trigger now (non-parallel guard)
   - GET  /external-review/last  ⇒ החזרה של consensus + per-provider
   - דשבורד: לשונית “External Review”
     • Cards: Consensus Score, Top-3 Risks, Top-3 Actions
     • Grid: Providers × Categories (ציון/10)
     • Log: קישורים ל־raw (JSON masked) + עלות/טוקנים
   - SSE עדכון כל 10s בזמן ריצה (spinner + ETA קצר).

5) Scheduler (Lite, 4GB):
   - utils/benchmark_scheduler.py מריץ גם reviewers:
     • 04:00 External Review (ריצה אחת, backoff אם RSS>3.0GB או active_trades>0)
     • Guard: CPU≤65%, RSS≤3.1GB, timeout לכל ספק 20–30s
   - 8GB future: EXTREV_REALTIME=on מרשה ריצות נוספות (שבועיות/טריגר טעויות).

6) Security & Cost:
   - Strict redact (no keys/ips), model=“no-training/use” אם נתמך, User-Agent מזוהה “AlgoGPT-Audit”.
   - Rate limit: ≤1 run/day בלייט (override דרך API עם reason).
   - Cost cap per run: ≤$0.50 (abort אם חזוי גבוה יותר).

- תוך ≤90s מתקבלות 2–3 חוות דעת, נשמרות ב-DB עם category_scores ו-overall_score.
- לשונית “External Review” מציגה Consensus + טבלת ספקים + עלויות.
- אין דליפת סודות (בדיקת redaction לוגים), שימוש זיכרון נשאר <3.1GB.
