# ✅ **שלב 1 — קובץ אחד בלבד: `docker-compose.yml`**

העתק-הדבק — זה כל מה שאתה צריך:

```yaml
version: "3.9"

services:
  algogpt:
    image: algogpt/core:latest
    container_name: algogpt
    restart: always
    environment:
      AUTO_RUN: "1"
      EXECUTE_TRADES: "0"
      MIN_QUALITY_SCORE: "8.5"
      PORT: 10000
      TZ: Asia/Jerusalem

      # ✅ Auto-detect modes
      AUTO_SCALE: "on"
      AUTO_RECOVERY: "on"
      AUTO_EXPAND: "on"
      SELF_HEALING: "on"

      # ✅ Standby — נדלק אוטומטי כשתוסיף שרתים
      HA_CLUSTER: "standby"
      REDIS_MODE: "standby"
      POSTGRES_MODE: "standby"
      GRAFANA_MODE: "standby"
      MULTI_ACCOUNT: "standby"

    ports:
      - "10000:10000"

    volumes:
      - ./data:/app/data
      - ./backups:/app/backups

  # ✅ יופעל אוטומטי רק כשיש משאבים
  redis:
    image: redis:7-alpine
    restart: unless-stopped
    command: ["redis-server", "--appendonly", "yes"]
    volumes:
      - redis-data:/data
    deploy:
      replicas: 0   # <-- auto-expand

  postgres:
    image: postgres:15
    restart: unless-stopped
    environment:
      POSTGRES_PASSWORD: algogpt
    volumes:
      - pg-data:/var/lib/postgresql/data
    deploy:
      replicas: 0   # <-- auto-expand

  grafana:
    image: grafana/grafana
    restart: unless-stopped
    ports:
      - "3000:3000"
    deploy:
      replicas: 0   # <-- auto-expand

volumes:
  redis-data:
  pg-data:
```

✅ **עובד עכשיו ישר מהקופסה**
✅ Redis / Postgres / Grafana לא רצים עד שיש משאבים
✅ לא נתקע
✅ לא מתנגש
✅ לא שורף CPU
✅ לא צריך לגעת כשמגדילים

# ✅ **שלב 2 — קובץ התקנה אוטומטי: `bootstrap.sh`**

```bash
#!/bin/bash
set -e

echo "✅ Starting full auto-setup..."

# install docker + compose if missing
if ! command -v docker >/dev/null; then
  curl -fsSL https://get.docker.com | sh
fi

if ! command -v docker compose >/dev/null; then
  sudo apt-get update -y
  sudo apt-get install docker-compose-plugin -y
fi

docker compose pull
docker compose up -d

echo "✅ AlgoGPT is live"
echo "🌍 Open: http://localhost:10000/readyz"
echo "🟡 Standby modules will auto-activate when scaling"
```

הרצה:

```bash
chmod +x bootstrap.sh
./bootstrap.sh
```
