## ✅ **1) AI NEWS-IMPACT ENGINE — NEW MODULE**

### **Data Sources (lightweight only):**

```
CryptoPanic API (filtered)
Binance announcements feed
Funding spikes alerts
Liquidation alerts (low rate)
AltRank sentiment (optional, cached)
```

### **Processing Rules:**

```
Poll every 15 minutes
Cache headlines for 6h
Classify into:
    + bullish impact
    - bearish impact
    0 neutral / noise
Remove duplicates and low-confidence items
```

### **Output:**

```
news_impact_score = -1.0 → +1.0
confidence = 0 → 1
event_type = normal | high-impact | critical
```

### **Integration Logic:**

```
IF high-impact news negative:
    block new longs for 45–90m
    tighten SL × 0.85
    disable auto-flip temporarily

IF high-impact news positive:
    allow continuation entries
    widen TP2 slightly
    enable trailing boost

IF critical news (both directions):
    freeze new entries for 60m
    reduce active position size -50%
    no auto-flip allowed
```

No notifications unless total freeze.
