## 🔄 4) Auto-Recovery אחרי קריסה

קובץ חדש: `utils/auto_recovery.py`

```python
import time
from utils.exchange_failover import health_check
from utils.auto_executor import restart_executor
from utils.telegram_notifier import send_admin

def auto_recover():
    try:
        health_check()
    except:
        time.sleep(5)
        try:
            health_check()
            restart_executor()
            send_admin("✅ SYSTEM AUTO-RECOVERED AND RESUMED TRADING")
        except:
            send_admin("🚨 RECOVERY FAILED — SYSTEM PAUSED")
            raise
```

קריאה אוטומטית ב־`main.py`:

```python
@app.on_event("startup")
async def startup_event():
    schedule.every(3).minutes.do(auto_recover)
```

## 🛑 5) Kill-Switch חכם

ב־`routes/system.py`:

```python
SYSTEM_PAUSED = False

@router.post("/pause")
def pause():
    global SYSTEM_PAUSED
    SYSTEM_PAUSED = True
    return {"status": "PAUSED"}

@router.post("/resume")
def resume():
    global SYSTEM_PAUSED
    SYSTEM_PAUSED = False
    return {"status": "RESUMED"}
```

ב־Executor:

```python
from routes.system import SYSTEM_PAUSED

if SYSTEM_PAUSED:
    return {"blocked": True, "reason": "system_paused"}
```
