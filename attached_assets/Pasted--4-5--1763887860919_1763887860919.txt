## ✅ 3) **Auto-HEDGING (קוד מלא)**

```python
class HedgeEngine:
    def activate(self, symbol):
        exposure = risk.get_exposure(symbol)
        ratio = min(exposure / risk.max_exposure, 1.0)

        hedge_size = ratio * 0.6  # dynamic hedge %
        bybit_client.open_hedge(symbol, size=hedge_size)

        self.active = True

    def deactivate(self, symbol):
        bybit_client.close_hedge(symbol)
        self.active = False
```

def balance(symbol):
    bin_pos = binance.get_position(symbol)
    by_pos  = bybit.get_position(symbol)

    diff = abs(bin_pos - by_pos)

    if diff > threshold:
        if bin_pos > by_pos:
            bybit.open_long(symbol, size=diff)
        else:
            bybit.open_short(symbol, size=diff)

## ✅ 6) **Heatmap ביצועים (קוד)**

```python
def build_heatmap(history):
    result = {}
    for trade in history:
        state = trade.market_state
        result.setdefault(state, {"wins":0,"loss":0})
        if trade.pnl > 0:
            result[state]["wins"] += 1
        else:
            result[state]["loss"] += 1
    return result
```
