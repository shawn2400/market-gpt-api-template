### 2) חיווט בתוך `utils/trade_manager.py` (בלבד, בלי שינויים חיצוניים)

בפונקציה `manage_open_trades()`:

1. אחרי שליפת המדדים (ATR/ADX/MACD/price/entry/qty/side):

   ```python
   from utils.regime_detector import detect_market_regime  # או market_intelligence
   regime = detect_market_regime(current_atr, current_adx, macd_now, volp=current_volp if defined else None)
   ```
2. בחירת פרמטרים דינמית:

   ```python
   params = _regime_adapter.pick_params(
       regime=regime,
       atr=current_atr,
       entry_price=entry,
       side=side,
   )
   sl_price = params["sl_price"]        # חייב להיות מבוסס ATR חי
   tp_levels = _regime_adapter.get_tp_ladder_levels(regime, entry, current_atr, side)
   ```
3. **Zero-Gap SL** (החלפה אטומית, Reduce-Only):

   ```python
   _sl_manager.safe_replace_sl(symbol=sym, new_stop_price=sl_price, qty=abs(qty), side=side)
   ```
4. **TP-Ladder דינמי**:

   ```python
   _tp_ladder.set_tp_ladder(sym, entry, abs(qty), side, tp_levels)
   ```
5. **BE + Trailing** (להשאיר לוגיקה קיימת, רק לוודא דגלים):

   * אם `TP_BE_ONLY_AFTER_TP1=1` → הזזת SL ל-BE+offset רק אחרי TP1.
   * Trailing לפי ATR אם `TRAIL_ENABLE=1`.

> הסר/נטרל חישובי SL/TP **קבועים** שהיו בפנים — שלא ירמסו את הדינמי.

### 3) היגיון זיהוי Regime (דיפולט סביר)

ב־`detect_market_regime()`:

* אם `ADX ≥ 22` ו־`|MACD| ↑` ⇒ `"TRENDING"`
* אם `ADX < 16` ו־`ATR_pct ∈ [0.8%, 2.0%]` ⇒ `"CHOPPY"`
* אם `ATR_pct ≥ 2.2%` ⇒ `"VOLATILE"`
* אחרת ⇒ `"SIDEWAYS"`

החזר גם `confidence` (0–1) לשימוש עתידי (לא חובה לשלב עכשיו).

### 6) בטיחות והחזרות

* אם `EXECUTE_TRADES=0` ⇒ הרץ **Dry-Run**: לחשב ולהדפיס, לא לשלוח/orders.
* ב־`safe_replace_sl` תמיד `Reduce-Only`, וודא תקינות `tickSize/stepSize`.
* ריטריי עדין (tenacity) על שגיאות API רגעיות (3 ניסיונות, backoff קצר).
