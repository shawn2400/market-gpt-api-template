# ✅ **שלב 8 — Auto-Installer מלא (Copy–Paste Ready)**

`install.sh`

```bash
#!/bin/bash

set -e

echo "🚀 Starting AlgoGPT Auto-Installer..."

# 1) Update system
apt update -y && apt upgrade -y

# 2) Install dependencies
apt install -y docker.io docker-compose python3-pip ufw

# 3) Create directories
mkdir -p /opt/algogpt/{storage,backups,logs}
mkdir -p /opt/algogpt/config

# 4) Fetch latest build (GitHub optional)
git clone https://github.com/YOUR_REPO/algogpt.git /opt/algogpt || true

# 5) Install Python packages
pip3 install -r /opt/algogpt/requirements.txt

# 6) Start services
docker-compose -f /opt/algogpt/docker-compose.yml up -d

echo "✅ AlgoGPT Installed Successfully!"
echo "📍 Dashboard: http://SERVER_IP:10000"
```

# ✅ **שלב 9 — Full HA Deploy ל-Hetzner (מוכן להרצה)**

`deploy_ha.yaml`

```yaml
cluster:
  nodes:
    - name: primary
      ip: 10.0.0.1
    - name: secondary
      ip: 10.0.0.2
    - name: recovery
      ip: 10.0.0.3

services:
  failover:
    type: keepalived
    virtual_ip: 10.0.0.100

  storage:
    type: ceph
    replication: 3

  app:
    mode: docker
    restart: always
```
