# 📊 AlgoGPT — LIVE Trading Orchestrator (FastAPI + Binance Futures)

מערכת מסחר אלגוריתמית בזמן-אמת על **FastAPI** עם:
- אישורי אופס מאובטחים **Bearer / HMAC + Anti-Replay (Redis)**  
- ניהול חי מלא: **TP / SL / BE / Trail / Ladder**  
- אינטגרציית **Telegram** דו-כיוונית  
- **Redis (עם TLS בפרוד)** עבור Idempotency / Anti-Replay / Stores  
- מצבי ביצוע: **HYBRID / MARKET / AUTO**  
- ניטור: **Prometheus + Grafana + Alertmanager + Blackbox + cAdvisor**  
- פריסה: **Docker Compose** (מקומי) / **Render** (Docker)

**גרסה:** `2.18.0`  
**ארכיטקטורה:** WS-only ל-Binance (fallback HTTP), Zero-Downtime Deploy

## יכולות
- **Ops Approval**  
  יצירת טיקט → תצוגת ווב + כפתורי אישור/דחייה בטלגרם.  
  **אישור חתום** `/ops/approve/signed` עם HMAC (`X-Timestamp`, `X-Nonce`, `X-Signature`) + Anti-Replay ב-Redis.  
  ConfirmStore (TTL + Idempotency) למניעת כפילויות.
- **Execution**  
  `MARKET` (מיידי), `HYBRID` (Limit±/Stop± + הסלמה), `AUTO` (HYBRID אם יש TP/SL, אחרת MARKET).
- **Live Trade Manager**  
  BE חכם + Offset/Guard, Trailing ATR דינמי לפי Regime/ADX, TP Ladder, Flip, Hedge Mode, PnL Tracker ודוחות יומיים.
- **Scanner & Scoring**  
  Multi-TF (5m/15m/1h/4h/1d), RSI/MACD/EMA(21/50)/ADX/ATR/Volume/OBV/BB; Quality Score (0–10), BTC-Anchor.
- **Guarder / Risk Rails**  
  Daily caps, 3-strikes, session rules, Kelly-lite, price protect.
- **ניטור ובריאות**  
  `/readyz`, `/readyz/strict`, `/health`, `/metrics` (Bearer), ו-`/ultra/*` (בריאות/מדדים/מטה/הפעלה חמה).

## אבטחה: Bearer / HMAC / Anti-Replay

**Bearer** — הוסף כותרת:

**HMAC (Sha256/Hex)**  
כותרות חובה: `X-Timestamp` (epoch שניות), `X-Nonce` (רנדומי), `X-Signature` (hex של HMAC).  
מבנה המסר לחתימה:
דוגמה ב-Python:
```python
import hmac, hashlib, json, time, os, requests
secret = os.environ["OPS_SIGN_SECRET"].encode()
ts = str(int(time.time()))
nonce = "n-"+ts
body = json.dumps({"patch":{"TP_DYNAMIC_ENABLE":1}})
msg = "|".join(["POST","/ultra/ops/runtime/prefs",ts,nonce,body]).encode()
sig = hmac.new(secret, msg, hashlib.sha256).hexdigest()

r = requests.post(
  "https://YOUR_HOST/ultra/ops/runtime/prefs",
  headers={"X-Timestamp":ts,"X-Nonce":nonce,"X-Signature":sig,"Content-Type":"application/json"},
  data=body
)
print(r.status_code, r.text)
