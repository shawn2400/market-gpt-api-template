מעולה. הולכים על **דינמי-על** בלי לשבור כלום ועם הגנות אמיתיות (בלי “חלון” בלי SL). להלן תכנון + קוד-הדבקה ממוקד שמממש בדיוק את מה שביקשת:

# מה משתנה (בקצרה)

* **Regime-Driven**: כל דקה `trade_manager` שואל `market_intelligence.get_regime()` ומנהל לפי מצב (Trending/Choppy/Volatile/Sideways).
* **Adaptive Targets**: SL/TP/Trail נקבעים מטבלת מצבים + התאמות לפי Quality-Score.
* **Zero-Gap SL**: החלפת SL תמיד “חד-אטומית” באמצעות `safe_replace_sl` (מבטל ישן **רק אחרי** שהחדש התקבל). אין מצב שנשארים בלי SL.
* **BE-Guard + Trail-Freeze**: Breakeven חכם + הקפאה זמנית ב־spike/ADX נמוך.

---

# טבלת דינמיות (ברירת מחדל)

| Regime       |                  SL בסיסי | TP Ladder                                      | BE-After-TP1 | Trailing   | הערות            |
| ------------ | ------------------------: | ---------------------------------------------- | ------------ | ---------- | ---------------- |
| **Trending** |        `2.0×ATR` מה־swing | `TP1=2.5×ATR, TP2=4×ATR, TP3=6×ATR, TP4=8×ATR` | כן           | Aggressive | ממנף איכות גבוהה |
| **Choppy**   | `0.8×ATR` (או מעבר לגריד) | `TP1=1.5×ATR, TP2=2.5×ATR`                     | כן           | כבוי/עדין  | העדפת GRID       |
| **Volatile** |                 `3.0×ATR` | `TP1=4×ATR, TP2=7×ATR`                         | כן           | מתון       | מרחיק יעדים      |
| **Sideways** |                 `1.2×ATR` | `TP1=2×ATR, TP2=3.2×ATR`                       | כן           | עדין       | mean-reversion   |

**התאמת איכות (QS):**

* `QS ≥ 8.5` ⇒ הרחב TP-ים ב־+20% והגדל מרחק SL ב־+10%.
* `QS ≤ 7.5` ⇒ הצמד: TP-ים -15%, SL -10% (להקטין drawdown).

```python
# utils/market_intelligence.py
from __future__ import annotations
import os
from typing import Literal, Dict

Regime = Literal["TRENDING","CHOPPY","VOLATILE","SIDEWAYS"]

def get_regime() -> Regime:
    """
    קביעה קלה ומהירה של מצב שוק.
    בפועל מומלץ לקרוא אינדיקטורים קיימים (BTC EMA21/50, ADX(15m/1h), ATR%) וחדשות.
    כאן: דוגם ENV כ-fallback כדי לא לשבור כלום.
    """
    # אפשר להחליף בהמשך ל: indicators.get_btc_gate(), get_adx(), get_atr_pct(), news_impact()...
    reg = os.getenv("FORCE_REGIME", "").upper().strip()
    if reg in {"TRENDING","CHOPPY","VOLATILE","SIDEWAYS"}:
        return reg  # ל־debug/בדיקות
    # TODO: קבע לוגיקה אמיתית: אם BTC>=EMA50 & ADX>=20 -> TRENDING; אם ADX<18 -> CHOPPY; אם ATR% גבוה -> VOLATILE; אחרת SIDEWAYS
    return "TRENDING"
```

```python
# --- ADD: dynamic regime/rules ---
from utils.market_intelligence import get_regime  # type: ignore

# פרופילי ברירת מחדל (ניתנים לאובררייד ע"י ENV)
_REGIME_PARAMS = {
    "TRENDING": {"sl_atr": 2.0, "tps_atr": [2.5, 4.0, 6.0, 8.0], "trail_mode": "aggr"},
    "CHOPPY":   {"sl_atr": 0.8, "tps_atr": [1.5, 2.5],           "trail_mode": "off"},
    "VOLATILE": {"sl_atr": 3.0, "tps_atr": [4.0, 7.0],           "trail_mode": "mid"},
    "SIDEWAYS": {"sl_atr": 1.2, "tps_atr": [2.0, 3.2],           "trail_mode": "mild"},
}

# התאמות לפי איכות
def _apply_quality_adjustments(qs: float, base: dict) -> dict:
    adj = dict(base)
    if qs >= 8.5:
        adj["sl_atr"] *= 1.10    # SL רחב יותר
        adj["tps_atr"] = [x*1.20 for x in adj["tps_atr"]]
    elif qs <= 7.5:
        adj["sl_atr"] *= 0.90    # SL קרוב יותר
        adj["tps_atr"] = [x*0.85 for x in adj["tps_atr"]]
    return adj
```

ועוד פונקציה שמחשבת יעדים מהמצב:

```python
def _compute_targets_by_regime(regime: str, qs: float, atr: float, swing_px: float, side: str, last_price: float) -> dict:
    """
    מחזיר: {"sl": float, "tps": [float,...], "trail_mode": str}
    מניח ATR וסוינג אחרונים זמינים. side in {"LONG","SHORT"}.
    """
    base = _REGIME_PARAMS.get(regime.upper(), _REGIME_PARAMS["TRENDING"])
    prof = _apply_quality_adjustments(qs, base)
    sl_mult = float(prof["sl_atr"])
    tps_mult = [float(x) for x in prof["tps_atr"]]

    if side.upper() == "LONG":
        sl = max(0.0, swing_px - sl_mult*atr)
        tps = [last_price + m*atr for m in tps_mult]
    else:
        sl = swing_px + sl_mult*atr
        tps = [last_price - m*atr for m in tps_mult]

    return {"sl": sl, "tps": tps, "trail_mode": prof["trail_mode"]}
```

```python
    # חלק לשלבים (50/30/20) או לפי פונקציה קיימת אצלך

except Exception as e:
    logger.error("[tm] set TPs failed %s: %s", sym, e)

# 4) Trail Mode לפי regime
trail_mode = targets["trail_mode"]
if trail_mode == "aggr":
    _enable_trailing(sym, side, sensitivity="high")
elif trail_mode in ("mid","mild"):
    _enable_trailing(sym, side, sensitivity="mid" if trail_mode=="mid" else "low")

    _disable_trailing(sym, side)
```

```python
def _place_tp(symbol: str, side: str, price: float, qty: float) -> None:
    """
    מציב TP reduceOnly. משתמש בסוג ברירת מחדל LADDER_TP_KIND (TAKE_PROFIT_MARKET) או Limit+offset אם מוגדר.
    """
    from utils.trade_executor import _fmt  # אם יש; אחרת פשט
    try:
        close_side = "SELL" if side.upper()=="LONG" else "BUY"
        # דוגמה פשוטה: TAKE_PROFIT_MARKET ב-Mark Price
        client = get_futures_client()  # קיים אצלך
        client.order_tp_or_sl_market(symbol.upper(), close_side, price, qty, kind="TAKE_PROFIT_MARKET",
                                     position_side="BOTH", reduce_only=True)  # קיימת אצלך לפי הקוד
    except Exception as e:
        logger.warning("[tm] place TP failed %s: %s", symbol, e)
```

# למה זה “הכי דינמי” (ולא שובר כלום)

* **Plug-in**: לא משנים API/חתימות קיימות; רק מוסיפים שכבה דינמית מעל אותם helpers (SL/TP/BE/Trail) שכבר אצלך.
* **Regime-Driven**: מחליף אסטרטגיה/פרמטרים ע״פ מצב שוק, בקצב בטוח (כל דקה, עם cooldown).
* **Quality-Aware**: ההחלטות גדלות/קטנות לפי QS בפועל – למידה קלה בלי “AI כבד”.
* **Zero-Gap SL**: אין שוב מצב של “ביטלנו ישן והחדש נדחה”. החלפה אטומית בלבד.
* **Kill-Switch/Freeze**: יש לך כבר `TRAIL_FREEZE_*` ו-Daily-Loss-Cap—אנחנו משתמשים בזה, לא ממציאים.
