## ✅ **1) Auto-Hedge Engine**

Create module:

```
engine/auto_hedge.py
```

Behavior:

* Trigger hedge ONLY if ALL true:

  * exposure_risk ≥ threshold
  * volatility regime = HIGH
  * funding flip detected
  * news impact = RED

Hedge rules:

```
if long_exposure > max_allowed:
    open short hedge on correlated symbol
    size = exposure * hedge_ratio
```

Hedge ratio dynamic:

```
0.25 → normal
0.5  → high risk
0.8  → extreme
```

Auto-unwind:

```
if risk_normalized for ≥ 30m:
    close hedge gradually
```

No manual approval required.
