TASK NAME: AlgoGPT — n8n Orchestration & Safety Bridge (4GB-safe)

מטרה: לחבר n8n כגשר אוטומציה חכם (חיצוני לליבה), עם 5 Flows:
1) Incident Router → קורא /economy-mode או /freeze-noncritical בעת עומס/כשל.
2) Approvals Fallback → טופס אישור/דחייה חתום (HMAC), לפעול רק אם Telegram לא זמין ובמצב TELEGRAM.
3) News Pre-Sanity → Allowlist + Dedup בסיסיים לפני Site, רק אם ה-News Ingest עמוס.
4) Scheduler → טריגרים מאקרו (CPI/FOMC/ETF) להורדת סיכון; Generate Reports Now “On demand”.
5) Webhook Gateway → נקודת בדיקות עשן/בריאות מאובטחת (HMAC).

Deliverables:
- 5 Workflows Activated (Production Webhook URLs), עם Rate-limit per endpoint, retry + backoff.
- Header Auth + HMAC: שלחו/קבלו תחת X-ALGO-SIGNATURE (sha256 HMAC(shared_secret) על body) + X-ALGO-TS + X-ALGO-NONCE.
- Secrets: N8N_SHARED_SECRET, N8N_BASE_URL מוגדרים; אין הדפסה של מפתחות (****last4).
- Site Integration: כפתור “Generate Now” שולח ל-n8n; Health page מושך status מ-"n8n/status".
- Core Integration: /economy-mode, /freeze-noncritical, /control/execution-mode (GET) – קריאות חתומות בלבד.
- Audit: כל פעולה דרך n8n נרשמת בליבה + רפרנס ל-Workflow ID + Execution ID.
- Persistence: לוודא Workflows במצב “Active” כך שה-Production URLs שורדים אתחול.

SLO:
- p95 זמן n8n-flow < 350ms; Runbook trigger ≤ 2s מרגע אירוע.
- אין חריגה ב-p95 API בליבה; אם יש → העבר ל-Safe profile באקסצ'יינג'ים.

Acceptance:
- סימולציית עומס → n8n מפעיל /economy-mode; חזרה אוטומטית ל-Normal כשהמדדים ירוקים.
- ניתוק טלגרם → n8n Form מייצר Approve/Reject חתום; ה-Audit מציג מקור=“n8n”.
- Restart n8n → ה-Webhooks עדיין פעילים (Workflow Activated, Production URL).
- News פריט עם דומיין לא מאושר → נחסם; מאושר → עובר לליבה עם tag “n8n-clean”.

הערות מחייבות:
- שמור על 4GB-safe: אין לולאות “חמות”; כל polling ≥ 60s; backoff + jitter.
- אל תכניס Mesh/Kafka. Redis בלבד דרך הליבה אם צריך Queue-ID.
- אל תשנה Auth/HMAC בליבה. רק להשתמש.
- הוסף “n8n Ready” card ל-Website: מצב, Latency, Executions Today, כפתור בדיקת ping.

סיים עם דו״ח קצר: n8n Bridge Report (endpoints, SLO, last executions, errors if any).
