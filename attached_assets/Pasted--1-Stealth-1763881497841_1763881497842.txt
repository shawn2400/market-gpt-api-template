def should_trade(self, heat_index, ml_signal, regime):

    # דרישות מינימום

# ✅ **2) Auto-Blacklist לסמלים רעים**

### קובץ חדש — `utils/symbol_blacklist.py`

```python
import time

class SymbolBlacklist:
    def __init__(self):
        self.blocked = {}  # symbol: unblock_time

    def add(self, symbol, hours=6):
        self.blocked[symbol] = time.time() + (hours * 3600)

    def is_blocked(self, symbol):
        expiry = self.blocked.get(symbol)
        if not expiry:
            return False
        if time.time() > expiry:
            del self.blocked[symbol]
            return False
        return True
```

### שילוב ב־סריקה:

```python
if blacklist.is_blocked(symbol):
    continue
```

### הפעלה אוטומטית:

```python
if pnl < -2 * atr:
    blacklist.add(symbol, hours=12)
```

✔ מונע מסחר בסמלים מסוכנים
✔ משתחרר לבד
✔ בלי ידיים
