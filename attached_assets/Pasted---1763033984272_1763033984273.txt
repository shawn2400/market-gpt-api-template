## 🔧 **הפיתרון המיידי - Trailing TP System:**

### **הוספת מנגנון Trailing Take Profit:**

```python
class TrailingTakeProfit:
    def __init__(self):
        self.activation_threshold = 0.25  # 25% רווח
        self.trailing_distance = 0.15     # 15% מתחת לשיא
        self.peak_price = None
        
    def update_peak(self, current_price, entry_price):
        pnl_percent = (current_price - entry_price) / entry_price
        
        if pnl_percent >= self.activation_threshold:
            if self.peak_price is None or current_price > self.peak_price:
                self.peak_price = current_price
                
    def should_close(self, current_price):
        if self.peak_price is None:
            return False
            
        drawdown = (self.peak_price - current_price) / self.peak_price
        return drawdown >= self.trailing_distance

# שימוש בפוזיציה הנוכחית:
trailing_tp = TrailingTakeProfit()
trailing_tp.update_peak(1.45, 1.2376)  # כשהגיע לשיא
# היה סוגר ב-1.45 * (1 - 0.15) = 1.2325 (עדיין 59% רווח)
```
