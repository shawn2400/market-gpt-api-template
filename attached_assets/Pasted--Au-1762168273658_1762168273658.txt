## TASK NAME: AlgoGPT — Auto-Manage Everywhere (Post-Approval & Web-Auto), Per-Exchange Visibility

**מטרה:**

1. לאחר **אישור בטלגרם** או **במצב אתר (WEB_AUTO)** — כל טרייד נכנס **אוטומטית** לניהול חי (SL→BE, ATR-Trail, TP-Shift, Auto-Flip A+, Grid לפי עומס).
2. גם **טרייד ידני** (מ־Ticket/CLI/API) → עובר **מיד** לניהול דינמי אוטומטי.
3. **שקיפות מלאה פר־בורסה**: מה נפתח/נסגר/ממתין, יתרות/חשיפות/קורלציות — עם שמות אחידים (Naming Policy).
4. **דוחות/מצב** באתר בלבד; טלגרם = אישור/דחייה בלבד.

---

### Deliverables — Backend (חתום + RBAC)

1. **Auto-Manage Hook (אחרי כל Entry)**

   * טריגר אחיד: `on_trade_opened(trade_id)` נורה מייד לאחר מילוי (Approved, Web-Auto, או ידני).
   * מפעיל **Position-AI**:

     * SL→BE guard, **ATR-Trail אדפטיבי** (ATR×N לפי Regime), **TP-Shift** לפי מומנטום/ΔOI, **Flip A+** בגבולות חשיפה, **Grid attach** אם “grid_ok=true”.
   * עומסים: עד **12** פוזיציות מנוהלות במקביל; Grid נרשם ל־Queue ייעודי (עדיפות נמוכה).
   * Idempotency לכל טריגר; ריצה חוזרת לא תכפיל ניהול.

2. **Execution Mode Enforcement (קיים, להדק)**

   * **TELEGRAM (ברירת מחדל):** כל הכרטיסים → Pending בטלגרם; לאחר Approve → Entry → Auto-Manage Hook מיידי.
   * **WEB_AUTO:** כרטיסים כשירים מתבצעים בלי אישור → Entry → Auto-Manage Hook מיידי.
   * כל טרייד שמקורו ידני (`source=manual/site/api`) → Entry → Auto-Manage Hook.

3. **Per-Exchange Registry & Snapshot**

   * טבלה/אובייקט:

     ```
     { id, name, venue ("BINANCE"|"BYBIT"|"OKX"), type ("FUTURES"|"SPOT"),
       status, health(latency/quota/errors), balances(equity, available, margin),
       positions[], rate_limit_profile, updated_at }
     ```
   * **Snapshot חתום** כל 30–60 שנ׳ להצגה באתר (ללא סודות).
   * רישום “מה נפתח/נסגר/ממתין” פר־בורסה.

4. **Naming Policy (אחיד בכל המערכת)**

   * **Exchanges:** `BINANCE_FUT`, `BYBIT_FUT`, `OKX_FUT`, `BINANCE_SPOT` …
   * **Symbols:** UPPERCASE, ללא מקפים (e.g., `BTCUSDT`).
   * **Trades:** `TRD-{venue}-{symbol}-{yyyymmdd}-{seq}` (למשל: `TRD-BINANCE_FUT-BTCUSDT-20251103-0042`).
   * **Grids:** `GRD-{venue}-{symbol}-{yyyymmdd}-{seq}`.
   * **Tickets:** `TCK-{source}-{symbol}-{timestamp}`.
   * אימוץ מדיניות בכל הלוגים/דוחות/DB.

5. **Unified Events (SSE + Audit)**

   * `trade.opened`, `trade.managed`, `sl.to_be`, `trail.update`, `tp.shift`, `flip.executed`, `grid.attached`, `trade.closed`.
   * כל אירוע כולל: `trade_id`, `venue`, `symbol`, `position_side`, `size`, `risk`, `rr_current`, `pnl_unrealized`, `policy_hits[]`.
   * **SSE batching** 3–5s; heartbeat 15s; עד 50 חיבורים (מעבר לזה → polling 5s).
   * **Audit Trail** חתום לכל פעולה.

6. **Guards & Risk (קשיחים)**

   * **VaR-Live 0.8–1.2%** לטרייד; **Daily Loss Cap 2–3%**; **Kelly-Lite ≤ 0.5×**.
   * **No-Chase > 0.3%**; Fill-Prob ≥ **0.62**; Exposure/Correlation guards.
   * Market Regime (Bull/Bear/Sideways/Volatile) מעדכן N ל-ATR-Trail/TP-Shift.

### Deliverables — Website (לשוניות קיימות + חדשות)

1. **Positions (שדרוג)**

   * תצוגה פר-בורסה (Tabs: BINANCE_FUT / BYBIT_FUT / OKX_FUT …).
   * לכל פוזיציה: מצב ניהול (ON), SL/BE, ATR-Trail (N), TP-Shift, Flip eligibility, Grid status.
   * פעולות Admin: SL→BE, Adjust Trail (N), Shift TP, Partial (10/25/50/100%), Flip A+ Only, Attach/Detach Grid.
   * Badge מקור: `APPROVED_TG` / `WEB_AUTO` / `MANUAL`.

2. **Trades (שדרוג)**

   * Log מסונן פר-בורסה: Opened/Managed/Closed; מזהה לפי Naming Policy.
   * “מה יצא” (closed) + “מה פתוח” (open) — מונה ברור; CSV/PDF export.

3. **Reports**

   * דוח 09:00/21:00 באתר בלבד: פר-בורסה — Open/Closed/PNL/Exposure/Correlation; **ללא טלגרם**.
   * “Generate Now” נשען על Snapshot האחרון.

4. **Settings → Exchanges**

   * רשימת בורסות + סטטוס + Health + “Sync Now”; הצגת מפתחות כ-`****last4`.
   * Enable/Disable venue בזמן אמת (Audit + SSE event).
