## ✅ **3) Docker Setup**

### Create `docker-compose.yml`

```yaml
version: "3.9"

services:
  api:
    build: ./server-api
    restart: always
    environment:
      MODE: "AUTO"
    ports:
      - "8000:8000"
    depends_on:
      - redis

  agent:
    build: ./agent-core
    restart: always
    depends_on:
      - api
      - redis

  redis:
    image: redis:7
    restart: always
    command: ["redis-server", "--appendonly", "yes"]
```

### Create `Dockerfile` for API:

```Dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY . .
RUN pip install -r requirements.txt
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```
