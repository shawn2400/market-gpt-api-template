**GOAL:** מנהל כספים/חדשנות חי (חלוקת רווחים דינמית ל-7 משתמשים, Growth Fund, סריקת עתיד, POC Lab, Canary/Flags) + **דוח מסודר באתר הפרטי** שמרכז כל שינוי שנוסף/הוסר/שודרג, עלויות, ROI, סטטוסים וקישורים — בזמן אמת, עם יצוא PDF/CSV חודשי.

---

## A) דוח אתר “מה חדש + דוחות כספיים”

### A1. לשונית חדשה: **כספים & חדשנות → דוחות**

כרטיסי KPI עליונים:

* **AUM**, **GF%/OO%/UP%**, **Runway (חודשים)**, **ΣSubscriptions**, **Monthly TCO**, **Innovation Velocity** (#POCs, % אימוץ).

טאבים:

1. **What’s New (חודשי/שבועי)** — מה נוסף/שופר/בוטל + מדדים.
2. **Changelog** — ציר זמן גרעיני (Prod/Canary/Disabled) לפי תאריכים.
3. **ROI & Cost Review** — גרף TCO 12–24 ח’, Cost/Req, Savings מול אלטרנטיבות.
4. **Decisions Log** — החלטות מוחות (JSON מקוצר), קונסנסוס, קישורים.
5. **Payouts/Expenses** — טבלאות חלוקה והוצאות (יצוא CSV).

פילטרים: תאריך, קטגוריה (Servers/News/Models/Subscriptions/OneOff), סטטוס (🟢 Approved / 🟡 Waitlist / ❌ Rejected / 🛠 Build / 🛰 Radar / 🧪 POC / 🚀 Prod).

### A2. מבנה כרטיס “מה נוסף”

* כותרת + אימוג’י קטגוריה (🛰/🧪/🚀/🛠/🗑️)
* **Status:** Radar | POC | Canary (1/10/50%) | Production | Retired
* **Why/Need:** 1–2 שורות תכל’ס
* **KPIs:** latency p95, coverage, accuracy/quality (אם רלוונטי), cost/req
* **Cost:** one-time / monthly / TCO-12m / TCO-24m
* **Decision:** approve/reject/build/waitlist + confidence
* **Links:** PRs / Docs / Provider / Dashboard
* **Owner:** שם אחראי + תאריך השקה

## B) API (FastAPI)

```text
GET  /reports/whats-new?from=YYYY-MM-DD&to=YYYY-MM-DD&category=&status=
GET  /reports/changelog?from=&to=
GET  /reports/roi
GET  /reports/payouts?month=YYYY-MM
GET  /reports/expenses?month=YYYY-MM
POST /reports/snapshot/generate   # יוצר PDF+CSV (חודשי/שבועי), שולח לטלגרם ומעדכן אתר
```

## C) DB (טבלאות חדשות/מורחבות)

* `reports_whatsnew(id,title,category,status,need,kpis_json,cost_json,decision_json,links_json,owner,launched_at,created_at)`

אינדקסים לפי `launched_at`, `category`, `status`.

## D) יצוא וקבצים

* **PDF/CSV** חודשי:

  * `export/reports/whats_new-YYYY_MM.pdf`
  * `export/reports/roi-YYYY_MM.csv`
  * `export/finance/finance_monthly-YYYY_MM.pdf`
* Job: `POST /reports/snapshot/generate` (cron חודשי/שבועי), יוצר קבצים ושולח לינקים לטלגרם.

## E) אינטגרציה ל-Telegram & n8n

* הודעת “What’s New” אחרי כל החלטה: כותרת + סטטוס + KPIs עיקריים + לינק לכרטיס באתר.
* Flow `reports_publisher`: כל `approve/build/canary→prod` → upsert ל-`reports_whatsnew` + פוסט לאתר/טלגרם.
* Rate-limit + idempotency_key למניעת כפילויות.

---

## F) אבטחה/ביצועים

* כל Endpoints ממוגנים Bearer + HMAC/nonce; Cache 60–300 שניות ל-GET.
* Export רץ ב-worker נפרד (async), Backoff ב-429/5xx, ולידציה סכמה ל-payloads.
* Counters: `report_items`, `pdf_exports`, `telegram_posts`, `roi_tco`, `savings`.
