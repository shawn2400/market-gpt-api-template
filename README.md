# 🚀 AlgoGPT – מערכת מסחר אלגוריתמית בזמן אמת

GPT אישי למסחר בקריפטו בזמן אמת עם חוקים קשיחים, ניתוחים טכניים, ניהול טריידים ו־Backtest חכם.

---

## 📦 תכולת הפרויקט

- `main.py` – שרת API עם Flask וניתוחי טכניים (RSI, MACD, ATR)
- `openapi.yaml` – הגדרה מלאה ל־Custom GPT
- `preset.txt` – חוקי ניהול קשיחים וסגנון פלט
- `requirements.txt` – תלויות Python
- תמיכה ב־📉 Backtest, 📊 גרפים, 🔒 בדיקת טרייד פתוח ועוד

---

git clone https://github.com/your-repo/algogpt
