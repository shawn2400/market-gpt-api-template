# 🤖 AlgoGPT Pro Elite – API למסחר חכם בקריפטו

מערכת מתקדמת לניתוח טכני, ניהול טריידים בזמן אמת, חישובי SL/TP, רטרוספקטיבה, גרפים והכל לפי חוקי Algo Pro Elite 2025 🚀  
מופעל ב־Render או Replit כ־Flask API.

---

## 🚀 תכונות עיקריות

- חישוב SL/TP עם יחס סיכון־רווח RRR ≥ 2.0
- תמיכה ב־Trailing SL ו־TP
- שמירת טריידים לפי חוקי Confidence ו־RRR
- ניתוח טכני מלא (RSI, MACD, ATR)
- בדיקת טרייד פתוח / סגירת טריידים
- Backtest (רטרוספקטיבה) אוטומטי
- תמיכה ב־LIMIT ו־STOP_LIMIT
- תמיכה ב־REGULAR ו־GRID
- ניתוח לפי 2 טיימפריימים (15m + 1h)
- גרף מובנה עם אינדיקטורים ✅
