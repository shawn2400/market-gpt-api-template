# 📊 AlgoGPT — מערכת מסחר חכמה בזמן אמת (Pro Elite Edition)

AlgoGPT היא מערכת מסחר אלגוריתמית אוטומטית הפועלת על Binance (Futures + Spot), מבצעת ניתוח טכני, סורקת מאות מטבעות בזמן אמת, שומרת טריידים, מפיקה דוחות PDF, ומבצעת טריידים חיים לפי כללים קשיחים.  
מתוכננת לרוץ על Render עם REST API יציב, כולל תמיכה מלאה ב־Grid חכם, Quality Scoring, ניתוח חדשות, SL/TP אוטומטי, ומערכת ניטור PNL.

---

## 🚀 תכונות עיקריות

- ✅ ניתוח טכני חי: RSI, MACD, EMA21/50, BB, ADX, ATR, OBV, Volume Spike
- ✅ חישוב SL/TP חכם כולל Trailing ו־ATR × 1.5 בלבד
- ✅ תמיכה במינוף 5×–35× לפי איכות וזמינות
- ✅ תמיכה בסוגי טריידים: Spot / Futures / Grid
- ✅ Smart Grid עם חלוקה ל־2 טריידים אם אין קורלציה
- ✅ כניסה רק לפי Breakout, Pullback או Reversal
- ✅ ניתוח Dual TF: טיימפריים 15m + 1h בלבד
- ✅ תמיכה ב־Limit / Stop Limit בלבד (אין Market SL/TP)
- ✅ הפקת דוחות PDF יומיים עם סטטיסטיקות, גרפים וציון הצלחה
- ✅ ניתוח איכות טריידים (quality_score) מ־0 עד 10
- ✅ מערכת שמירה וניהול טריידים (`trades_log.json`)
- ✅ ניתוח חדשות וסנטימנט חי מ־CryptoPanic
- ✅ תמיכת REST API מלאה

---

## 🧠 הרחבות Pro Elite

- 📌 Confidence משתנה: 88%+ או 86% עם quality ≥ 4
- 📌 מינוף דינמי לפי גובה הסיכון (5× עד 35×)
- 📌 PNL Tracker חי ו־Snapshot לכל טרייד
- 📌 Auto Risk Allocation לפי תנודתיות ויחס RRR
- 📌 Order Type חכם לפי סוג תנועה (Volatile vs Stable)
- 📌 חיזוי טווחים עם Prophet AI (ב־/ai-analyze)
- 📌 הגנה מפני טריידים כפולים (Active Trade Enforcement)
- 📌 Trailing SL חכם (callback + activation)
- 📌 ניתוח נרות, פערים, Volume, OBV וכיווני מגמה
- 📌 תשתית ל־Backtest → Analyze → Confirm → Execute

## 📡 REST API — נתיבים

| נתיב                  | תיאור                                               |
|-----------------------|------------------------------------------------------|
| `/`                   | בדיקת תקינות השרת                                   |
| `/scan`               | סריקה טכנית חיה לפי Binance Futures                |
| `/backtest`           | בדיקה היסטורית לפי אסטרטגיה                        |
| `/execute-trade`      | שליחת טרייד חי בפועל (Spot/Futures)               |
| `/sl_tp`              | חישוב SL ו־TP לפי תנודתיות ויחס RRR               |
| `/calculate-quantity` | חישוב כמות לפי תקציב, מינוף ומחיר נכנס            |
| `/save`               | שמירת טרייד למעקב                                  |
| `/trades`             | הצגת כל הטריידים השמורים                           |
| `/open-trades`        | הצגת טריידים פתוחים                                |
| `/close-trade`        | סגירת טרייד לפי סימול                              |
| `/daily-report`       | הפקת דוח PDF יומי עם סיכום וגרף                    |
| `/ai-analyze`         | חיזוי AI גרפי לפי Prophet                          |
| `/stats`              | סטטיסטיקת PNL ו־Win Rate                           |
| `/news`               | חדשות קריפטו מ־CryptoPanic + ניתוח השפעה         |
| `/preset`             | שליפת הגדרות מערכת                                 |
| `/strategy`           | תיאור כללי האסטרטגיה                               |
